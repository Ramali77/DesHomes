В визуализацию входят:
Панорама  ​— вид интерьера 360°
Пролет камеры по интерьеру (видео формат)
Рендеринг 4-6 ракурсов (графический формат)

Для постановки задачи необходимо:

  • наличие плана (обязательно)
  • цветовая гамма (желательно для Варианта 1)
  • пожелания по мебели (опционально для Варианта 1)
  • пожелания по освещению (опционально для Варианта 1)
