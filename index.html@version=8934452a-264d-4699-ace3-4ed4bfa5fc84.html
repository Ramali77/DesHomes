ОФИС СО СТУДИЕЙ

Техническое задание:
Визуализировать перепланировку офиса с возведением или переносом стен таким образом, чтобы на площади 80 кв.м. разместилось три зоны:

  • зона совещаний
  • тихая зона для работы сотрудников
  • комната-студия для записи видео-роликов

Исходные данные: Чертеж площади для перепланировки

Решение

Вариант перепланировки № 1 (эскиз):

  • переговорная (7.92 кв.м.)
  • студия (15.58 кв. м.)
  • опенспейс  — тихая зона (63.62 кв. м.)
